# 📜 Server Rules

Following these rules helps keep Vanguard a fun place for everyone.

## General Rules

1. **Be respectful** to all players and staff
2. **No griefing** or destroying others' builds
3. **No hacking** - This includes x-ray, aimbot, or any unfair advantages
4. **English only** in public chats
5. **No spamming** or excessive caps

## Chat Rules

- Keep chat family-friendly
- No advertising other servers
- No excessive swearing
- Don't share personal information

## Building Rules

- Don't build within 100 blocks of other players without permission
- No offensive builds (racist, sexual, etc.)
- Respect claim boundaries

## Punishment System

| Offense | Punishment |
|---------|------------|
| First warning | Verbal warning |
| Second offense | 1-hour mute/kick |
| Third offense | 24-hour ban |
| Severe offense | Permanent ban |

*Staff have final say in all decisions*
