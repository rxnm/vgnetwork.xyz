# Welcome to Vanguard! 🎉

We're thrilled to have you join our community. This guide will help you get started.

## First Steps

1. **Join our Discord** - Click the Discord link in navigation
2. **Read the rules** - Check the #rules channel
3. **Introduce yourself** - Say hi in #introductions
4. **Connect to the server** - Use `play.vgnetwork.uk`

## Server Information

- **IP:** `play.vgnetwork.uk`
- **Version:** 1.20.4
- **Website:** https://vgnetwork.uk
- **Discord:** [Join here](https://discord.gg/your-discord)

## Getting Help

Need assistance? You can:
- Use `/help` in-game
- Ask in Discord #support
- Tag a staff member (@Staff)

## Tips for New Players

- Complete the tutorial first
- Join a clan for bonuses
- Check events daily
- Don't be afraid to ask questions!
